# Chat UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Corrigir 7 problemas de UX no chat: layout do botão enviar, ícones que somem ao digitar, pré-visualização de foto, câmera/galeria em todos os uploads, bio no modal de perfil, busca de conversas funcional, e sheet de seleção de fonte de imagem reutilizável.

**Architecture:** Novo componente `ImageSourceSheet` centraliza a lógica câmera/galeria e é usado em todos os fluxos de upload. Pull-to-refresh implementado via evento `touchstart`/`touchmove` em CSS puro no React (sem biblioteca extra). Busca de conversas por filtro local no estado.

**Tech Stack:** React + TypeScript, Vitest + React Testing Library, Tailwind CSS

Bugs cobertos: #3 (preview foto), #4/#15 (câmera em todos os uploads), #8 (botão enviar), #9 (ícones somem ao digitar), #10 (bio no modal), #16 (busca de conversas)

- [ ] **Step 2: Substituir lógica de foto para mostrar preview primeiro**

```tsx
// Substituir handlePhotoSelected por:
async function handleFileSelected(file: File) {
  const objectUrl = URL.createObjectURL(file)
  setPhotoPreview({ file, url: objectUrl })
}

// Novo handler para confirmar envio:
async function handlePhotoConfirm() {
  if (!photoPreview) return
  setIsUploadingPhoto(true)
  const preview = photoPreview
  setPhotoPreview(null)
  URL.revokeObjectURL(preview.url)
  try {
    const resized = await resizeImage(preview.file, 1200, 1200, 0.85)
    const url = await uploadImage(resized, accessToken)
    sendMutation.mutate({ imageUrl: url })
  } catch {
    // silently discard
  } finally {
    setIsUploadingPhoto(false)
  }
}

function handlePhotoCancelPreview() {
  if (photoPreview) URL.revokeObjectURL(photoPreview.url)
  setPhotoPreview(null)
}
```
